# Reproducible original archive

Run `python scripts/regenerate_coordinates.py` from the checkout. All gzip files use fixed mtime=0. 6-original-epochs.json.gz retains the full original trained base, four datasets, four original widths with all 31 epoch boundaries each, metrics and unchanged original report. These are 124 states, not every online update. 7-witnesses.json.gz has 48 complete trajectory reports; 8-controls.json.gz has six complete non-scalar/sign/zero-rate controls. docs/5-data.js is the same full archive for the independent browser evaluator. COORDINATES.md documents schema, numerical tolerance, original online-vs-diagnostic distinctions and limitations. No private or real-user training data is present.
