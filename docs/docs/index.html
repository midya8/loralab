Multiply one factor by a scale and divide the other by it. Predictions stay the same. An ordinary factor-SGD update usually does not.

Inspect the finite-step identity on the original three-class experiment. The base, online training, four factor widths and all original results stay attached. This is an arithmetic diagnostic, not a new LoRA optimizer or an LLM benchmark.

01 / Choose a recorded model

Change the coordinates, not the past.

The diagnostic is one simultaneous factor update at a fixed state. A mean full-batch gradient is not an original online epoch. No selection retrains a model. The original online learning rate is 0.5.

Coordinates: B' = B C and A' = C⁻¹ A. A scalar gauge uses C = c I, with 1/32 ≤ |c| ≤ 32. A full matrix gauge is available below. Ordinary Euclidean SGD is invariant to orthogonal changes of basis in exact arithmetic; scaling and shear need not preserve its update.
Custom finite-classifier input and matrix gauge

2 to 8 classes, 1 to 128 features, factor width 1 to 8, and 1 to 256 labeled examples. Every input number is finite and bounded by ±1,000,000. The base bias is frozen.

Matrix inversion uses pivoting and rejects pivots below 1e-12 or a computed infinity-condition estimate above 1e6. These are operational bounds, not numerical rank or conditioning certificates.

02 / Model equality is not update equality

What changed after one step?

For gradient G = ∂L/∂(BA), simultaneous factor SGD gives:

Δ(BA) = -ηₐ B Bᵀ G - ηᵦ G Aᵀ A + ηₐηᵦ G (BA)ᵀ G

The second-order term is retained. This is a real-arithmetic identity checked by the displayed binary64 residual, not an outward-rounded certificate. The loss is stable mean softmax cross-entropy. Original training logs add 1e-12 inside the probability logarithm; these diagnostic losses do not.

What this cannot tell you
Factor scaling changes the Euclidean metric used by ordinary SGD. The scalar learning-rate compensation is a coordinate identity, not a proposed optimizer. It does not choose a better scale, explain the original retention outcome, or establish a benefit for Adam, transformers, sequence models or unseen tasks. A frozen finite example cannot identify a general training mechanism.
The fixture uses synthetic token vocabularies and hashed bag-of-words features. Token order is discarded; hashing can collide. Test accuracy and retained accuracy describe the original seeded examples, not deployment quality. The base bias is frozen for adapters but trainable for the full fine-tuning baseline, as in the unchanged original experiment.
Floating reassociation can change logits or a near-tied prediction. An inverse residual, equality residual or parameter-count formula is not a safety, convergence or generalization guarantee.
