A linear-softmax rank inspector

How much rank
changes a prediction?

An adapter can change every logit without changing a single probability. Separate the matrix you store from the class differences softmax can see.

Inspect constructive upper bounds and nonzero-minor lower bounds, in exact rational arithmetic. Keep the original model, frozen bias, all 124 recorded epoch boundaries and the earlier coordinate-SGD experiment intact.

This is an exact statement about a linear output classifier, with its base and bias fixed. It is not a new compression method, a training result, an LLM benchmark or a guarantee about rounded runtime probabilities.

01 / Choose the claim you can prove

Width is not predictive rank.

Archive factors are decoded as the exact rational values represented by their binary64 numbers, before multiplying B A. They are not the rounded entries of a merged update. Coordinate probes e₀, e₁, … are chosen for transparent algebra, not as representative data or evaluation examples.

02 / A lower bound and a model that attains it

Erase the common class motion.

For update M = B A and reference class t, let Dⱼ = Mⱼ − Mₜ. The reference row becomes zero. Every all-input equivalent linear softmax update has these same row differences, so its rank is at least rank(D). A rank factorization of D attains that bound.

min rank(N) subject to softmax((W+N)x+b) = softmax((W+M)x+b) for all x
= rank(D)

Each certificate supplies factors whose product is the audited matrix, and a square minor with a nonzero exact determinant. The product proves an upper bound; the minor proves a matching lower bound. Rank zero uses empty factors and the conventional empty determinant 1.

03 / Agreement has a domain

Finite probes cannot see every direction.

With probe rows X, the least rank needed to match their class differences is rank(D Xᵀ). The displayed extension constructs that rank and matches every supplied probe. This can be smaller than the all-input rank. Only a full feature-spanning probe set forces global equality.

Constructive probe-blind direction

When probes do not span all features, u is nonzero and X u = 0. Adding uᵀ to the indicated non-reference class row of the probe extension is invisible on every probe. At x = u, its class contrast changes by uᵀu > 0. Even a canonical extension that happens to equal D does not make a non-spanning probe set complete.

Exact algebra has a boundary.
The equivalence fixes W and b and ranges over all real feature inputs. It relies on a linear output map followed directly by softmax. It does not apply unchanged to a hidden transformer layer, nonlinear map, temperature changes, changed bias, optimizer state or subsequent factor training. It is probability equivalence, not literal logit equality.
Exact rank is discontinuous: an arbitrarily tiny nonzero rational can raise it. A numerical rank threshold answers another question. Casting exported factors to binary64, matrix reassociation, underflow, overflow and near-tied predictions can change runtime behavior. The inspector makes no floating-point probability, loss or argmax certificate and does not measure inference performance.
